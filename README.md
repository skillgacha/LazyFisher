# LazyFisher (Auto Clicker)

シンプルで軽量な Windows 用自動連打ツールです。
インストール不要で、ダウンロードして (`.exe`) を実行するだけですぐに使えます。

## 📥 ダウンロード
[**最新版のダウンロードはこちら (Releases)**](https://github.com/skillgacha/LazyFisher/releases)
> `LazyFisher.exe` をクリックしてダウンロードしてください。

## 🎮 使い方

### 基本操作
- **開始 / 停止**: `F6` キー（デフォルト）
  - アプリ内の「開始」ボタンを押してもスタートできます。
  - もう一度押すとストップします。

### 設定項目
#### 1. クリック間隔 (Interval)
連打するスピードを設定します。
- 初期設定: **8秒** に1回
- 「時間」「分」「秒」「ミリ秒」で細かく指定可能です。

#### 2. クリックオプション
- **マウスボタン**: 左クリック / 右クリック / 中クリック
- **タイプ**: シングル / ダブルクリック
- **押し続け時間**: クリックしたままにする時間（長押しが必要なゲーム等で有効）

#### 3. 繰り返し設定
- **停止するまで繰り返す**: 停止キーを押すまで無限に続けます。
- **指定回数**: 設定した回数だけクリックして自動停止します。

#### 4. カーソル位置
- **現在の位置**: マウスカーソルがある場所でクリックします。
- **固定位置**: 画面上の特定の場所を記憶して、そこをずっとクリックし続けます。
  - 「位置をクリップ」ボタンを押し、好きな場所で `F6` を押すと座標が登録されます。

### その他の機能
- **常に最前面**: 他のウィンドウより手前に表示し続けます。
- **ホットキー変更**: `F6` 以外のキー（Ctrl+Qなど）に変更できます。

## 動作環境
- Windows 10 / 11 (64bit)
- .NET Runtime のインストールは**不要**です。
